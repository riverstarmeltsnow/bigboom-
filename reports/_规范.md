# 实验报告生成规范

## 模板格式（基于 上机报告4.docx）
- 标题居中：「应用密码学实验报告」16pt 加粗
- 学生信息用文本段落（非表格），14pt：
  - 课程：应用密码学    实验名称：XXX
  - 姓名：何鑫            实验日期：YYYY.M.D
  - 学号：2024121065      实验报告日期：YYYY.M.D
  - 班级：网工242
- 章节：一、→ 二、→ 三、→ 四、→ 五、→ 六、→ 七、
  - 标题 14pt 加粗，正文 12pt，行距 1.3
  - 英文/数字用 Times New Roman，中文用宋体
- 附录代码：Consolas 7.5pt，行距 1.0

## 关键流程
1. 模板放 templates/，截图放 images/
2. `.doc` 文件先用 WPS COM（KWps.Application）转真 `.docx`
3. python-docx 读模板 → 清空旧段落内容 → 复用段落位置写新内容（不追加，避免空白页）
4. 代码字符串用单独文件读写，避免 `\0` 等控制字符导致 lxml 报错
