## 学到的经验

1. **和风天气账号体系**：项目 ID、凭据 ID、API Key 是三个不同东西。项目 ID 在 console URL 里，凭据 ID 是创建时生成的，API Key 是创建凭据时选的认证方式
2. **专属域名**：2024年后新注册的账号都需要用项目专属域名（控制台→设置可查），不能用旧版 `devapi.qweather.com`
3. **JWT 认证限制**：免费版不支持 JWT，付费版才支持。JWT Token 最长 24 小时，header 需带 `kid`（凭据ID），payload 的 `sub` 填项目 ID
4. **小程序网络调试**：
   - 模拟器 ↔ 真机调试 ↔ 预览 是三个不同环境，网络行为可能不同
   - 真机调试通过开发者工具隧道转发，请求从电脑 IP 发出
   - 预览直接从手机发出，受运营商和第三方 API 安全限制影响
5. **API 安全**：小程序前端代码明文打包，API Key 会被任何人看到。生产环境必须用后端代理
