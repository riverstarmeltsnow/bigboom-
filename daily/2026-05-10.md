## 学到的经验

1. **小程序 WXML 的限制**：不能直接在模板里调用 JS 函数（如 `formatWeekday`），需要在 JS 层预处理数据，或者用 WXS 模块。这次选择了 JS 预处理，否则 WXML 里写不了复杂表达式
2. **和风天气 API 设计**：位置参数是 `经度,纬度`（注意顺序），城市搜索支持输入坐标做反向地理编码
3. **毛玻璃效果**：小程序支持 `backdrop-filter: blur()`，但需要搭配 `rgba` 背景色使用
4. **定位权限声明**：小程序需要在 `app.json` 中声明 `requiredPrivateInfos: ["getLocation"]`，否则真机调试会失败
